# Team documentation

This is the implementation framework, not a runnable application. All tasks begin unchecked; paths and contracts describe intended work. The [project README](../README.md) explains scope and stack.

## Start here

1. Read [requirements](requirements.md) and [architecture](architecture.md).
2. Claim a role in the [team directory](roles/README.md).
3. Review the [data contract](data-contract.md) and [API contract](api-contract.md) with dependent owners.
4. Pick the first ready task in the [backlog](backlog.md).
5. Follow [contributing](../CONTRIBUTING.md); record decisions in [decisions](decisions.md).

## Working references

- [Setup plan](setup.md): bootstrap, accounts, environment, and expected commands.
- [Provider research](provider-research.md): evidence, data access, and integration questions.
- [Testing](../tests/README.md): acceptance scenarios and evidence.
- [Deployment](deployment.md): preview, release, and rollback gates.
